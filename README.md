# Chemical Anchors Calculator

Интерактивный калькулятор ориентировочного расхода инъекционного состава для химических анкеров.

## Задача
Быстро оценить необходимый объём состава для выбранной геометрии отверстия, глубины установки и типа крепежа.

## Что показывает проект
- Перевод инженерной прикладной задачи в работающий веб-инструмент.
- Расчётная логика, пользовательский ввод, проверка граничных случаев и отображение результата.
- Автономный интерфейс в одном `index.html`.

## Запуск
Откройте [index.html](index.html) в браузере. Приложение предназначено для статического размещения, например через GitHub Pages, после включения Pages в настройках репозитория.

**Важно:** демонстрационный инструмент, не является сертифицированным инженерным ПО. Перед фактическим применением необходимо сверить методику, коэффициенты и результат с документацией производителя.

## Технологический подход
HTML / CSS / JavaScript. Разработка с использованием ИИ как инструмента; постановка задачи, отбор решений, проверка и тестирование — автор проекта.
